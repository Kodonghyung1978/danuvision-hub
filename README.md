# 다뉴비전랩 업무허브

> 세상을 바꿔 나가는 비전솔루션 전문기업 — 다뉴비전랩의 업무 관리 시스템

## 소개

다뉴비전랩 업무허브는 기업의 목표 설정부터 프로젝트 관리, 업무 추적, 문서 관리까지 통합적으로 지원하는 웹 기반 업무 관리 시스템입니다.

## 주요 기능

- **목표 관리**: 기업 목표 설정 및 달성률 추적
- **프로젝트 관리**: 프로젝트 생성, 상태 관리, 마일스톤 추적
- **업무 관리**: 프로젝트별 세부 업무 등록 및 진행 관리
- **문서 관리**: 프로젝트 관련 문서 등록 및 분류

## 사용 방법

### 로컬 실행
`index.html` 파일을 웹 브라우저에서 직접 열면 됩니다.

```
# 브라우저에서 직접 열기
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

### 데이터 관리
- 데이터는 브라우저의 `localStorage`에 자동 저장됩니다.
- 좌측 메뉴 하단의 **내보내기** 버튼으로 JSON 백업 가능
- **가져오기** 버튼으로 백업 데이터 복원 가능

## 기술 스택

- 순수 HTML/CSS/JavaScript (의존성 없음)
- localStorage 기반 데이터 저장
- 반응형 디자인 (모바일 지원)
- 다크/라이트 테마 지원

## 데이터 구조

```
danuvision_hub_db (localStorage key)
├── goals[]        — 기업 목표
├── projects[]     — 프로젝트
├── tasks[]        — 세부 업무
└── documents[]    — 문서
```

## 업무 프로세스

시스템 분석 → 솔루션 제안 → 시작품 제작 → 시험제품 → 성능검증 → 양산
